# website

Personal site, built with Astro. Local only for now.

    npm install
    npm run dev       # http://localhost:4321
    npm run build     # static output in dist/

- Home page text, signs and social links: `src/data/site.ts`
- Background art: `src/components/MountainScene.astro`
- Figures (layer above the title): `src/components/SceneFigures.astro`; `Figures.astro` is generated by `python3 -I scripts/fig_astro.py src/components/Figures.astro`
- Signpost + hover effect: `src/components/Signpost.astro`

Design source: "Personal Website Prototypes" canvas, Round 11, Q1 (place names + small text).
